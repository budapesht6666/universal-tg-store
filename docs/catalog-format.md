# Формат меню

Меню — один JSON-файл: характеристики блюд, категории и блюда. Им заполняется магазин при первой настройке («Загрузить демо-меню»), он же — формат импорта и экспорта. Настройки магазина (название, Telegram менеджера, часы работы, валюта) в файл не входят — они задаются мастером настройки и хранятся в БД.

- Пример: [`catalog/example.catalog.json`](../catalog/example.catalog.json) — демо-меню домашней кухни.
- JSON Schema: [`catalog/catalog.schema.json`](../catalog/catalog.schema.json). Если в начале файла указано `"$schema": "./catalog.schema.json"`, VS Code подсказывает поля и подчёркивает ошибки прямо при вводе.
- Источник правды — zod-схемы в [`packages/schema`](../packages/schema/src). JSON Schema генерируется из них командой `pnpm schema:gen`, руками её не правим.

## Общие правила

| Что                 | Правило                                                                                                           |
| ------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Деньги              | Целое число в **минимальных единицах валюты**. У донга дробной части нет: `65000` = 65 000 ₫. Для рубля — копейки |
| `id`                | Латиница в нижнем регистре, цифры и дефис: `borscht`. До 64 символов, уникален в своём списке                     |
| Ключи характеристик | Латиница и цифры, начинается с маленькой буквы: `portion`, `kcal`                                                 |
| Картинки            | `{ "url": "https://…", "alt": "…" }`; `url` — ссылка `https://` или путь к загруженному файлу `/uploads/…`        |
| Неизвестные поля    | Ошибка. Так опечатка (`"prise"` вместо `"price"`) не потеряется молча                                             |

Поля со значением по умолчанию можно не писать — при разборе они подставятся.

## Верхний уровень

```jsonc
{
  "$schema": "./catalog.schema.json", // необязательно, для подсказок в редакторе
  "version": 2,                        // версия формата, обязательно
  "attributes": [ … ],                 // характеристики блюд
  "categories": [ … ],
  "products": [ … ]                    // блюда
}
```

## `categories`

```json
{ "id": "soups", "title": "Супы", "sort": 10 }
```

`sort` — порядок вкладок в меню (по возрастанию), по умолчанию 0.

## `products` — блюда

```jsonc
{
  "id": "borscht", // обязательно
  "title": "Борщ с говядиной", // обязательно, до 120 символов
  "description": "Со сметаной и чесночной пампушкой", // состав, обычный текст до 1000 символов
  "price": 85000, // обязательно
  "compareAtPrice": 100000, // старая цена, должна быть больше price
  "images": [{ "url": "https://…", "alt": "Борщ" }], // до 5 фото, первое — главное (в меню)
  "categoryId": "soups", // обязательно, категория должна существовать
  "badges": ["Хит"], // до 3 меток, до 24 символов
  "available": true, // false — «Закончилось»: видно, но заказать нельзя
  "isActive": true, // false — скрыто из меню
  "sort": 10, // порядок внутри категории
  "attributes": { "portion": "600 мл", "kcal": 450 },
  "createdAt": "2026-11-14T09:00:00Z",
  "updatedAt": "2026-11-14T09:00:00Z"
}
```

## `attributes` — характеристики блюд

Свои поля блюда без правки кода: порция, калорийность, острота… Описание — FieldDefinition плюс два флага показа:

```jsonc
{
  "key": "portion",
  "label": "Порция",
  "type": "text",
  "maxLength": 40,
  "placeholder": "400 г или 500 мл",
  "required": false,
  "showInCard": true, // в карточке меню (по умолчанию false)
  "showInSpecs": true // на странице блюда (по умолчанию true)
}
```

Значения проверяются по описанию: неизвестный ключ, значение не того типа, выход за `min`/`max`, вариант не из списка — ошибка с путём до значения.

### Типы полей (`type`)

Общие свойства: `key`, `label`, `hint`, `placeholder`, `required` (по умолчанию `false`).

| `type`        | Значение              | Дополнительные свойства                        |
| ------------- | --------------------- | ---------------------------------------------- |
| `text`        | строка                | `minLength`, `maxLength` (по умолчанию до 500) |
| `textarea`    | строка                | `maxLength`                                    |
| `markdown`    | строка с разметкой    | `maxLength`                                    |
| `number`      | число                 | `min`, `max`, `integer`, `unit`                |
| `money`       | сумма                 | `min`, `max`                                   |
| `boolean`     | `true` / `false`      | —                                              |
| `select`      | один из `options`     | `options` (список строк)                       |
| `multiselect` | список из `options`   | `options`, `maxItems`                          |
| `url`         | ссылка `https://…`    | —                                              |
| `image`       | `{ url, alt }`        | —                                              |
| `images`      | список `{ url, alt }` | `maxItems`                                     |
| `tags`        | список строк          | `maxItems`                                     |
| `date`        | `ГГГГ-ММ-ДД`          | —                                              |
| `color`       | `#RRGGBB`             | —                                              |

Из одного описания строятся проверка значения (одна и та же на сервере и в админке — `buildZodSchema`) и поле формы блюда в админке.

## Проверка и ошибки

`parseCatalog(json)` из `@store/schema` проверяет файл целиком и возвращает либо нормализованное меню, либо **все** ошибки сразу, с путём до места:

```
products[3].price: Сумма не может быть отрицательной
products[1]: Неизвестное поле «prise» — проверьте написание
products[0].categoryId: Нет категории «drinks»
products[1].id: Блюдо «borscht» уже есть (повтор, первый — №1)
products[0].attributes.kcal: Не больше 5000
```

С ошибками меню не загружается — база не меняется.

## Версии формата

`version` — номер формата, сейчас 2. Старые файлы обновляются при загрузке автоматически (`MIGRATIONS` в `packages/schema/src/parse.ts`). Файл новее, чем понимает шаблон, не загружается — будет понятная ошибка.

- 1 → 2: одно фото `image` стало списком `images` (до 5, первое — главное). Файл версии 1 с `image` загружается как `images: [image]`.

## Как расширить формат

1. Добавьте поле в zod-схему в `packages/schema/src/catalog.ts` (со значением по умолчанию — тогда старые файлы останутся валидными).
2. Новая фича меню — новый флаг в `FeaturesSchema` (`packages/schema/src/settings.ts`).
3. `pnpm schema:gen` — обновить JSON Schema; тест сверяет её с zod-схемой.
4. Обновите этот документ и демо-меню.

Для своих полей блюда код не нужен — это `attributes`.
