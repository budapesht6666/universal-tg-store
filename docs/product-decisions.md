# Продуктовые решения

Первый проект на шаблоне — **доставка еды во Вьетнаме**: цены в донгах, интерфейс только на русском, оплата курьеру при получении (в приложении её нет), доставка бесплатная.

Принцип: **клиенту — заказать в пару касаний; менеджеру и курьеру — всё на одном экране телефона и один чат с ботом**. Меню и настройки удобнее править с компьютера.

Менять эти правила — только осознанно, вместе со схемами в `packages/schema`. Макеты — в [`design/`](../design/README.md).

## Первая настройка

- При первом запуске владелец (его Telegram id — в `OWNER_TELEGRAM_ID` в `.env`) пишет боту `/start` и получает кнопку «Настроить магазин». Мастер из трёх шагов:
  1. **Страна** (Вьетнам по умолчанию) — из неё валюта, часовой пояс и код телефона. Название магазина, Telegram менеджера (необязательно).
  2. **Часы работы** — по умолчанию каждый день 10:00–22:00, можно поменять по дням.
  3. **Меню** — «Загрузить демо-меню» или «Начать с пустого».
- Сразу после — подсказка «Пригласите курьера» (ссылка из раздела «Команда»).
- **Валюта, часовой пояс и код страны после настройки не меняются**: смена валюты молча переоценила бы все цены (65000 ₫ ≠ 65000 копеек). Поэтому в админке выбора валюты нет.

## Часы работы и пауза

- Пока магазин закрыт, меню видно и корзину собрать можно, но кнопка оформления недоступна: «Сейчас закрыто · откроемся завтра в 10:00». Сервер тоже отклоняет заказ вне часов работы.
- Ночные смены поддерживаются (18:00–02:00), выходной день — `null`.
- **Пауза приёма заказов** — один переключатель в шапке экрана заказов: «на 30 мин», «на час», «до конца дня». Для случаев «завал на кухне» или «курьер один и занят». Пауза снимается сама.

## Оформление (клиент)

Одна страница, фиксированная форма:

| Поле                | Обязательно | Как                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Имя                 | да          | Подставляется из Telegram                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Телефон             | да          | Ручной ввод, со второго заказа — из прошлого. Местный `0912…` → `+84912…`. Кнопки «Взять из Telegram» нет: `requestContact` отправляет контакт сообщением в чат с ботом ещё до заказа, а номер в Telegram у туристов часто не местный                                                                                                                                                                                                                                                                   |
| Точка на карте      | да          | Пин по центру карты, карту двигают под ним. «Я сейчас здесь» — геопозиция Telegram (LocationManager), только на телефоне: Telegram на компьютере её не отдаёт; если погрешность больше 50 м — просим подвинуть карту. Можно вставить ссылку Google Maps (и текст из «Поделиться») или координаты из Zalo / Grab — точка встанет на карту. Короткие `maps.app.goo.gl` раскрывает сервер: таймаут, только домены Google. В заказ идут координаты пина (+ погрешность), курьер получает ссылку Google Maps |
| Дом, этаж, квартира | нет         | Текст                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Комментарий         | нет         | «Без лука», «позвонить у ворот»                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

- Кнопки «вставить из буфера» нет: `readTextFromClipboard` в Mini App работает только у ботов из меню вложений — обычное поле, вставка долгим нажатием.
- Данные запоминаются: второй заказ — одним нажатием.
- Максимум 50 порций одного блюда. Цены сервер берёт из БД, клиенту не доверяет.
- Минимальной суммы и платы за доставку нет. Оплата — курьеру, в приложении её нет.

## Меню

- Блюдо: название, состав, цена, фото, категория (одна), метки, «Есть / Закончилось», «Скрыто».
- **«Закончилось»** (стоп-лист): блюдо видно в меню серым, заказать нельзя. Переключается одним касанием — с телефона тоже. Остатков в штуках нет.
- **Старая цена**: если указана, показывается зачёркнутой рядом с «−15%». Только отображение, без промокодов и скидок на корзину. Выключается флагом `features.discounts`.
- **Метки**: до трёх коротких надписей на карточке («Хит», «Острое 🌶», «Вег»). Флаг `features.badges`.
- Порция и калорийность — характеристики (`attributes`), порция видна в карточке.
- В магазине меню — одна лента по разделам с закреплёнными вкладками категорий сверху (как в Grab Food): нажал вкладку — лента прокрутилась к разделу.

## Статусы заказа

Один словарь для магазина, админки и бота (источник — `packages/schema`):

```
Оформлен → Готовим → Курьер в пути → Доставлен
    └──────────┴────────────┴──────► Отменён
```

- «Доставлен» и «Отменён» — конечные. Допустимые переходы проверяет сервер, гонки — условный `UPDATE ... WHERE status = ?`.
- Экран заказа у покупателя: крупно — текущее состояние и чего ждать, полоса прогресса, история. Каждая смена статуса — сообщение бота со ссылкой на заказ.

## Оценка и отзыв

- Когда заказ «Доставлен», на экране заказа у покупателя — «Как вам заказ?»: 1–5 звёзд (обязательно) и отзыв (необязательно, до 1000 символов). Сообщение бота «Доставлен» — с кнопкой «⭐ Оценить заказ».
- Один раз на заказ, без редактирования. Включается флагом `features.reviews` («Оценка и отзыв после доставки» в настройках, по умолчанию вкл.).
- Отзыв видит только менеджер, курьеру не показывается. На карточке в «Готово» — «★ 4 · новый отзыв» и подсветка, без звука и без сообщения в бот. Первый менеджер, раскрывший карточку, снимает пометку для всех.
- Заказ с отзывом поднимается наверх «Готово» на сутки, непрочитанный отзыв висит там, пока его не откроют.

## Отмена

| Кто        | Когда               | Как                                                                                                                |
| ---------- | ------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Покупатель | «Оформлен»          | Сам, с подтверждением. Отключается настройкой «Покупатель может отменить заказ сам» (по умолчанию вкл.)            |
| Покупатель | «Готовим», «В пути» | «Попросить отменить» — просьба приходит менеджеру                                                                  |
| Менеджер   | До «Доставлен»      | Причина обязательна (закончилось блюдо / не дозвонились / покупатель попросил / другое). Причина уходит покупателю |

## Команда

- Роли: **владелец**, **менеджер**, **курьер**; у одного человека может быть несколько: владелец после настройки — он же первый курьер (пока курьер один, заказы назначаются ему сами), роль курьера с себя можно снять в «Команде».
- Приглашение — одноразовая ссылка на 24 часа из раздела «Команда»; бот просит поделиться номером. Выключенный участник сразу теряет доступ.
- Курьера назначает менеджер одним касанием. **Если курьер один — назначается автоматически.** «Курьеры берут сами» — позже.

## Как работают менеджер и курьер (телефон)

**Рабочее место — Mini App из бота**, кнопка меню «Заказы». Вход автоматический через Telegram, ничего устанавливать не нужно, работает на любом телефоне.

**Менеджер — экран «Заказы»**, всё на одном экране:

- Шапка: «Принимаем заказы до 22:00» + переключатель паузы.
- Вкладки: **Новые** (со счётчиком) · **В работе** · **Готово**. Новые сверху, подсвечены, с таймером «ждёт 4 мин».
- Карточка заказа раскрывается на месте: состав, сумма, имя, кнопки **Позвонить** · **Написать** · **Карта**, и одна большая кнопка следующего шага: «Принять и готовить» → «Передать курьеру» (выбор курьера, если их несколько) → дальше ведёт курьер. Отмена — в меню «⋯».
- Пока экран открыт, новые заказы появляются сами, со звуком и вибрацией.

**Курьер — тот же экран, режим «Мои доставки»**: только назначенные ему заказы. В карточке — большая кнопка **Открыть в Google Maps**, **Позвонить**, состав и сумма к оплате («Получить 145 000 ₫»), кнопка шага: «Забрал, еду» → «Доставлен». «Не получилось» с причиной возвращает заказ менеджеру. После доставки адрес и телефон покупателя у курьера скрываются.

**Уведомления — один чат с ботом**, чтобы не пропустить заказ:

- **Новый заказ** — сообщение со звуком всем менеджерам и владельцу: «🆕 Заказ #1042 · 145 000 ₫ · 3 позиции» и кнопки [Принять] [Открыть]. **Пока заказ не принят — напоминание каждые 3 минуты** («⏰ #1042 ждёт уже 6 мин»).
- Когда заказ приняли, сообщение у всех **обновляется на месте** («✅ Принял Иван»), а напоминания прекращаются: чат не засоряется.
- Курьеру — сообщение со звуком при назначении: адрес, кнопки [Карта] [Забрал, еду].
- Остальные изменения — без звука или не присылаются вовсе. Так звук в этом чате всегда значит «нужно действие».
- Чтобы звук нового заказа отличался от остальных чатов, достаточно поставить на чат с ботом свой звук уведомления в Telegram (Настройки чата → Уведомления → Звук).

**Переписка с клиентом — тоже через бота.** Клиент пишет боту → сообщение приходит менеджерам с номером заказа. Только пока заказ в работе (новый, готовится, в пути); после доставки или отмены и без заказа менеджерам ничего не уходит — защита от спама. Вместо этого бот отвечает сам (не чаще раза в минуту): «Этот чат — для вопросов по заказу в работе…», «По другим вопросам напишите менеджеру: @… — ответит в рабочее время, как только освободится» (если менеджер указан в настройках) и «Сделать заказ — кнопка «Меню» внизу». Подсказка «Вопрос по заказу — напишите в чат с ботом» на экране заказа — тоже только пока заказ в работе. Менеджер отвечает на него свайпом «Ответить» → бот пересылает клиенту. Кнопка «Написать» в карточке открывает чат с клиентом в Telegram напрямую, если у клиента есть username.

**Телефон магазина нигде не показываем и не храним** (решение 15.11.2026). Контакт магазина — Telegram-аккаунт менеджера (`settings.shop.manager`, необязательный): на экране заказа карточка «Менеджер в Telegram · @…» с кнопкой «Написать» (`openTelegramLink`, Mini App закрывается), позвонить покупатель может из его профиля в Telegram. Не указан — карточки нет, строки в автоответе бота тоже.

## Админка (компьютер)

- Тот же веб-интерфейс, адаптивный. На компьютере вход по одноразовой ссылке от бота: команда `/login` или кнопка «Открыть на компьютере» → ссылка на 5 минут → сессия в браузере на 30 дней. Без настройки OIDC и домена в BotFather.
- Разделы: **Заказы** · **Меню** · **Команда** · **Настройки**.
- **Меню** — один экран: слева список категорий (перетаскивание для порядка, переименование, добавление, удаление пустой), справа блюда выбранной категории: фото, название, цена, переключатель «Есть», порядок перетаскиванием. Клик по блюду — форма справа. Отдельного раздела «Категории» нет.
- **Настройки**: магазин (название, логотип, Telegram менеджера, тексты бота), часы работы, «Покупатель может отменить заказ», фичи (старая цена, метки). Регион показывается только для чтения.
- Импорт и экспорт меню JSON-файлом — позже (формат и проверка уже есть в `packages/schema`).
