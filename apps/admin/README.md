# @store/admin

Админка — одно веб-приложение для телефона и компьютера, открывается по `/admin`.

- **Телефон** — Mini App из бота (кнопка меню «Заказы»): экран заказов менеджера и «Мои доставки» курьера, стоп-лист одним касанием. Вход автоматический по initData.
- **Компьютер** — меню, команда, настройки. Вход: `/login` в боте → ссылка на 5 минут → cookie на 30 дней.
- **Первая настройка** — владелец пишет боту `/start` → «Настроить магазин» → мастер из трёх шагов (`/admin/setup`).

```bash
pnpm dev                                # из корня: сервер (:3000), магазин (:5173), админка (:5174/admin/)
pnpm --filter @store/admin build        # dist/ раздаёт сервер по /admin
```

Локально в браузере без cookie админка входит как владелец через `/api/dev/init-data` (только `NODE_ENV=development`).

| Раздел     | Кто                | Что                                                                                                                                                                               |
| ---------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Заказы `/` | менеджер, курьер   | пауза приёма, Новые · В работе · Готово, принять, передать курьеру, отмена с причиной; курьер — «Забрал, еду», «Доставлен», «Не получилось». Новые заказы — со звуком и вибрацией |
| Меню       | владелец, менеджер | категории (порядок, переименование, удаление пустой), блюда (до 5 фото, цены, метки, характеристики, «Есть», «Скрыто»)                                                            |
| Команда    | владелец           | роли, выключить доступ, ссылка-приглашение курьеру или менеджеру                                                                                                                  |
| Настройки  | владелец           | магазин, приветствие бота, часы работы, отмена покупателем, фичи меню                                                                                                             |

Формы проверяются схемами из `@store/schema` (те же, что на сервере); ошибки сервера показываются у своих полей. Порядок в меню — стрелками (перетаскивание — позже).

Ссылка на блюдо — `src/components/DishLink.tsx`: у сохранённого блюда, если бот подключён (`dishLink` из `GET /api/admin/catalog`). «Скопировать» кладёт полную ссылку `https://t.me/<бот>?startapp=dish_<id>`; пока в BotFather не включён Main Mini App — жёлтое предупреждение (сервер проверяет раз в минуту, перезапуск не нужен).

Фото блюда — `src/components/PhotoGallery.tsx`: до 5, первое — главное. Можно выбрать сразу несколько файлов или перетащить их на блок; каждый файл — отдельный запрос `POST /api/admin/uploads`, параллельно, фото встают в порядке выбора, лишние сверх 5 не грузятся. Порядок — перетаскиванием (HTML5 drag-and-drop) или ★ «Сделать главным» (на телефоне). Сохраняются вместе с формой, пока идёт загрузка — «Сохранить» неактивна.
