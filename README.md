# Universal TG Store

Шаблон интернет-магазина в виде Telegram Mini App: меню, корзина, оформление заказа с доставкой курьером, рабочий экран менеджера и курьера, админка. Первый проект на нём — доставка домашней еды «Печка» (Вьетнам, донги, оплата курьеру).

**Покупателю** — заказать в пару касаний: меню → корзина → точка на карте → «Оформить». Статус заказа приходит в чат с ботом.
**Менеджеру и курьеру** — всё на одном экране телефона и один чат с ботом: новый заказ со звуком, «Принять», «Передать курьеру», «Забрал, еду», «Доставлен».
**Владельцу** — меню, команда и настройки с компьютера, вход по ссылке от бота.

## Быстрый старт

```bash
corepack enable pnpm
cp .env.example .env      # токен бота, свой Telegram ID, два случайных секрета
pnpm install
pnpm dev                  # сервер :3000, магазин :5173, админка :5174/admin/
```

Бот в BotFather, проверка в Telegram через туннель, деплой на сервер — [docs/deploy.md](docs/deploy.md).

## Что внутри

| Где                     | Что                                                                                                                                     |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `packages/schema`       | формат меню, заказов и настроек: zod-схемы и типы для сервера и обоих фронтендов, деньги, телефоны, часы работы, статусы и отмена, роли |
| `apps/server`           | API, бот (уведомления, напоминания, приглашения, переписка с покупателем), SQLite, фото — [README](apps/server/README.md)               |
| `apps/shop`             | Mini App покупателя — [README](apps/shop/README.md)                                                                                     |
| `apps/admin`            | админка: заказы на телефоне, меню, команда, настройки, мастер первой настройки — [README](apps/admin/README.md)                         |
| `catalog/`              | демо-меню и JSON Schema формата — [docs/catalog-format.md](docs/catalog-format.md)                                                      |
| `design/`               | утверждённые макеты                                                                                                                     |
| `docs/`                 | [продуктовые решения](docs/product-decisions.md), [запуск и деплой](docs/deploy.md)                                                     |
| `Dockerfile`, `deploy/` | образ и файлы для VPS (схема vps-ops: Docker + Caddy)                                                                                   |

```bash
pnpm typecheck && pnpm lint && pnpm test   # проверки
pnpm build                                 # магазин и админка → сервер раздаёт их сам
pnpm schema:gen                            # обновить JSON Schema каталога
```

## Как адаптировать под свой проект

- **Бренд** — акцент в `apps/shop/src/index.css` и `apps/admin/src/index.css` (блок `:root`); всё остальное берётся из темы Telegram.
- **Город на карте** — `DEFAULT_CENTER` в `apps/shop/src/components/MapPicker.tsx`.
- **Страна, валюта, часы, название** — мастер первой настройки; новые страны — `REGIONS` в `packages/schema/src/settings.ts`.
- **Характеристики блюд** (порция, калорийность…) — `attributes` в меню, без новых колонок.
- **Правила заказов** — [docs/product-decisions.md](docs/product-decisions.md); менять вместе со схемами в `packages/schema`.
- Позже: онлайн-оплата, добавки к блюдам, выбор времени доставки, импорт меню из JSON в админке.
