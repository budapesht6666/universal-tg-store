# Макеты (Claude Design)

Исходники утверждённого дизайна. Живая версия с холстом — в Design-артефакте Claude (ссылка у владельца проекта); здесь копия, чтобы макеты версионировались вместе с кодом.

Файлы `*.dc.html` — артборды Claude Design: разметка с привязками `{{...}}` и класс `Component` с логикой прототипа. Вне Claude Design они не открываются как обычные страницы (нужен рантайм `support.js` из типа артефакта), но читаются как спецификация: тексты, токены, состояния, сценарии.

На холсте две страницы: **«MVP — Печка»** — актуальные макеты первого проекта, **old** — первая версия шаблона (универсальный магазин; часть решений там уже отменена, сверяться с `docs/product-decisions.md`).

### MVP — Печка (действующие)

| Файл | Что внутри |
|---|---|
| `Brand.dc.html` | Бренд «Печка»: знак, надпись, аватар бота, иконка, цвета, шрифт |
| `ShopMenu.dc.html` | Меню: одна лента, закреплённые вкладки категорий, «Закончилось», старая цена, метки, кнопка корзины |
| `ShopClosed.dc.html` | Корзина, когда закрыто или пауза (переключатель в Tweaks) |
| `ShopCheckout.dc.html` | Оформление: точка на карте («Я сейчас здесь» / ссылка Google Maps), дом, контакты, комментарий |
| `ShopOrder.dc.html` | Заказ покупателя: «Доставлен», оценка звёздами и отзыв («Спасибо за отзыв!» — в Tweaks), подсказка про чат по заказу и карточка «Менеджер в Telegram» с кнопкой «Написать» (без менеджера карточки нет — в Tweaks) |
| `StaffOrders.dc.html` | Менеджер на телефоне: пауза, вкладки Новые / В работе / Готово, раскрытая карточка |
| `StaffCourier.dc.html` | Курьер: «Мои доставки», сумма к получению, Google Maps, «Забрал, еду» → «Доставлен» |
| `BotNotify.dc.html` | Бот: новый заказ и напоминания, сообщение обновилось на месте, ответ клиенту, назначение курьеру |
| `BotCustomer.dc.html` | Бот покупателю: приветствие на /start, статусы заказа и «⭐ Оценить заказ», автоответ на сообщение без заказа |
| `AdminMenu.dc.html` | Админка «Меню»: категории + блюда + форма блюда на одном экране |
| `AdminOrdersBoard.dc.html` | Админка «Заказы» на компьютере: три колонки Новые / В работе / Готово, пауза, режим «Мои доставки» |
| `AdminTeamMvp.dc.html` | Админка «Команда»: роли, доступ, приглашение ссылкой |
| `AdminSettingsMvp.dc.html` | Админка «Настройки»: магазин, бот в Telegram, часы, заказы и меню, регион — две колонки |
| `AdminLogin.dc.html` | Вход в админку по ссылке от бота: подсказка, «Входим…», ссылка устарела (переключатель в Tweaks) |
| `SetupWizard.dc.html` | Мастер первой настройки: страна, часы, меню, «магазин открыт» |
| `brand/*.svg` | Знак и аватар бота в SVG (для BotFather — сконвертировать в PNG 640×640) |

### old (первая версия)

| Файл | Что внутри |
