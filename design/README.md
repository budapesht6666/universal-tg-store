# Макеты (Claude Design)

Исходники утверждённого дизайна. Живая версия с холстом — в Design-артефакте Claude (ссылка у владельца проекта); здесь копия, чтобы макеты версионировались вместе с кодом.

Файлы `*.dc.html` — артборды Claude Design: разметка с привязками `{{...}}` и класс `Component` с логикой прототипа. Вне Claude Design они не открываются как обычные страницы (нужен рантайм `support.js` из типа артефакта), но читаются как спецификация: тексты, токены, состояния, сценарии.

На холсте две страницы: **«MVP — Печка»** — актуальные макеты первого проекта, **old** — первая версия шаблона (универсальный магазин; часть решений там уже отменена, сверяться с `docs/product-decisions.md`).

### MVP — Печка (действующие)

| Файл | Что внутри |
|---|---|
| `Brand.dc.html` | Бренд «Печка»: знак, надпись, аватар бота, иконка, цвета, шрифт |
| `ShopMenu.dc.html` | Меню: обложка-печь (название и «Доставка: …»), лист меню со статусом и «Мои заказы», закреплённые вкладки, «Закончилось», «Осталось 3» и «+» не больше остатка, старая цена, метки, фирменные заглушки вместо фото, подпись внизу (Tweaks: view = end), кнопка корзины |
| `ShopDish.dc.html` | Страница блюда: слайдер до 5 фото (точки, свайп), метки, цена и скидка, описание целиком, плитки характеристик, «Добавить» → счётчик и «Корзина»; без фото, мало порций («Осталось 3», «+» до остатка), «Закончилось», «блюда больше нет» — в Tweaks (state, qty) |
| `ShopClosed.dc.html` | Корзина, когда закрыто или пауза (переключатель в Tweaks) |
| `ShopCheckout.dc.html` | Оформление: точка на карте («Я сейчас здесь» / ссылка Google Maps или Apple Maps), дом, контакты, комментарий, кнопка «Проверить заказ». Tweaks `geo`: outside — «Сюда не доставляем», coarse — «Точка примерная», linkError — ссылку не распознали |
| `ShopConfirm.dc.html` | «Проверьте заказ»: неподвижная карта с пином и строкой «откуда точка», получатель, состав, «Подтвердить заказ». Tweaks `point` (link, gps, pin, last, coarse, poor) и `state` (error — блюдо закончилось, stock — порций меньше, чем в корзине) |
| `ShopOrder.dc.html` | Заказ покупателя: «Доставлен», оценка звёздами и отзыв («Спасибо за отзыв!» — в Tweaks), подсказка про чат по заказу и карточка «Менеджер в Telegram» с кнопкой «Написать» (без менеджера карточки нет — в Tweaks) |
| `StaffOrders.dc.html` | Менеджер на телефоне: пауза, вкладки Новые / В работе / Готово, раскрытая карточка, метка «Первый заказ» |
| `StaffCourier.dc.html` | Курьер: «Мои доставки», сумма к получению, Google Maps, «Забрал, еду» → «Доставлен» |
| `BotNotify.dc.html` | Бот: новый заказ и напоминания, сообщение обновилось на месте, ответ клиенту, назначение курьеру |
| `BotCustomer.dc.html` | Бот покупателю: приветствие на /start, статусы заказа, «ещё не приняли» через 15 минут и «⭐ Оценить заказ», автоответ на сообщение без заказа |
| `AdminMenu.dc.html` | Админка «Меню»: категории + блюда + форма блюда на одном экране; фото блюда — до 5, «Главное», ★ сделать главным, загрузка и лимит (Tweaks: photos); «Ограничить порции» и «Осталось порций», значок «12 порц.» в списке (Tweaks: stock) |
| `AdminAnalytics.dc.html` | Админка «Аналитика»: период, пять плиток (выбирают график), график по дням, воронка и брошенные корзины, популярные блюда, заказы по часам, покупатели, источники (startapp), работа и качество, бот — сколько заблокировали (Tweaks: state = fresh) |
| `AdminOrdersBoard.dc.html` | Админка «Заказы» на компьютере: три колонки Новые / В работе / Готово, пауза, режим «Мои доставки» |
| `AdminTeamMvp.dc.html` | Админка «Команда»: роли, доступ, приглашение ссылкой |
| `AdminSettingsMvp.dc.html` | Админка «Настройки»: магазин, бот в Telegram, часы, заказы и меню (в т. ч. «Страница блюда»), регион — две колонки; внизу зона доставки (карта с кругами) |
| `AdminLogin.dc.html` | Вход в админку по ссылке от бота: подсказка, «Входим…», ссылка устарела (переключатель в Tweaks) |
| `SetupWizard.dc.html` | Мастер первой настройки: страна, часы, меню, «магазин открыт» |
| `brand/*.svg` | Знак и аватар бота в SVG (для BotFather — сконвертировать в PNG 640×640) |
