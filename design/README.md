# Макеты (Claude Design)

Исходники утверждённого дизайна. Живая версия с холстом — в Design-артефакте Claude (ссылка у владельца проекта); здесь копия, чтобы макеты версионировались вместе с кодом.

Файлы `*.dc.html` — артборды Claude Design: разметка с привязками `{{...}}` и класс `Component` с логикой прототипа. Вне Claude Design они не открываются как обычные страницы (нужен рантайм `support.js` из типа артефакта), но читаются как спецификация: тексты, токены, состояния, сценарии.

| Файл | Что внутри |
|---|---|
| `Main.dc.html` | Кликабельный прототип Mini App: каталог (плитка/список), карточка, корзина, оформление, мои заказы, экран заказа, отмена |
| `ShopScreens.dc.html` | Все экраны магазина в светлой и тёмной теме |
| `Tokens.dc.html` | Цвета, радиусы, типографика, маппинг на `themeParams` Telegram |
| `Admin*.dc.html` | Веб-админка: товары, форма товара, импорт, заказы, настройки, характеристики, команда, тёмная тема, боковое меню |
| `BotCourier.dc.html` | Как курьер работает в боте |
| `canvas.json` | Раскладка артбордов на холсте |

Продуктовые решения, принятые по ходу дизайна, — в [`docs/product-decisions.md`](../docs/product-decisions.md).
